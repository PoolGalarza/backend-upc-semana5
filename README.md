# Backend UPC - Semana 5

Proyecto del laboratorio de Arquitectura de Aplicaciones Web.

## Ejecutar localmente

```bash
npm install
npm start
```

Luego probar:

- http://localhost:3000/api/v1/health
- http://localhost:3000/api/v1/info

## Configuración en Render

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Instance Type: Free

Después del despliegue, probar:

`https://TU-SERVICIO.onrender.com/api/v1/health`
